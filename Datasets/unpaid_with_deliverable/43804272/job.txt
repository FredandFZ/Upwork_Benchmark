Job Title
Senior Mobile Developer (Android & iOS) – Scoliometer App Update, 77+ Language Localization, & Size Optimization

Job Description
Overview
We are seeking an experienced, detail-oriented Mobile App Developer (or small agency) to update and optimize our existing application, Scoliometer App, for both Android and iOS platforms.

The core objectives of this project are to bring the current source code up to modern standards, implement an extensive localization strategy across dozens of languages, and optimize the app's footprint to ensure it remains as lightweight as possible.

Key Responsibilities
• OS & Framework Updates: * Update the existing source code to support the latest versions of iOS and Android OS/firmware.
• Refactor outdated APIs, deprecated libraries, and dependencies using current platform-recommended best practices (e.g., modern layout systems, Swift/Kotlin updates, or latest Flutter/React Native versions depending on the existing stack).

Massive Localization & Translation String Build:
• Set up and manage translation strings for global deployment.
• Google Play: Configure and implement localizations for 77 languages.
• App Store (iOS): Configure and implement localizations for 50 supported languages.
• Ensure proper RTL (Right-to-Left) layout support where applicable.

App Size Optimization:
• Audit and minimize the app binary size to keep it as small as possible.
• Implement Android App Bundles (.aab) and leverage iOS App Thinning/Slicing.

Optimize assets, graphics, and translation files to prevent bloat.
• Required Skills & Qualifications
• Proven experience in native (Swift/Kotlin) or cross-platform (Flutter/React Native) mobile development—please specify your expertise in your proposal based on our existing stack.
• Deep understanding of Apple App Store and Google Play Store localization guidelines and string management.
• Expertise in app size optimization techniques (asset compression, code stripping, dynamic delivery).
• Strong track record of updating legacy codebases to comply with the latest App Store and Google Play console requirements.
• Excellent communication skills and clean code documentation.

Application Questions for Candidates
• Can you share an example of a previous app you updated for modern OS compliance? What challenges did you face?
• What is our existing codebase stack (Native iOS/Android, Flutter, or React Native)? [Note: We will provide access to the repository to the shortlisted candidates].
• What strategies do you typically use to keep the app binary size as small as possible when dealing with over 50+ localized language files?
