job_name:
Custom Beverage Mixing Device Prototype (DJ-Style Matcha Mixer)

job_description:
We are looking for a mechanical/product engineer to help design and prototype a custom beverage mixing device for live event use.

This device is a dual-station matcha mixing system inspired by DJ turntables, designed to create a visually engaging experience while mixing powdered beverages (matcha).

Project Overview:

The device will include:

Two circular mixing stations (“decks”)
Motorized whisking mechanism in each station
Independent speed control for each side
Central control panel (knobs/switches)

The goal is to create a functional prototype that:

Mixes matcha smoothly (similar to handheld electric whiskers)
Looks visually impressive for live events
Is safe and practical for repeated use

Key Requirements:

1. Dual Mixing System

Two independent mixing bowls (8–12 inches diameter)
Food-safe materials (stainless steel preferred)

2. Mixing Mechanism

Motor-driven whisk or similar solution
Must create smooth, frothy consistency
Variable speed control

3. Control Interface

Speed control knobs (one per mixing station)
Power switch
Simple, intuitive layout

4. Build Considerations

Use off-the-shelf components where possible (for prototype)
Durable and stable structure
Easy to clean

5. Noise Level

Should not be excessively loud (used in event environments)

Design Direction:

We will provide a visual concept (DJ-style layout), but we are not locked into exact design details.

We are looking for someone who can:

Translate concept into a working prototype

Suggest the simplest and most cost-effective approach

Deliverables:

Concept refinement / recommendations
Basic CAD or design drawings
Parts list (BOM)
Prototype guidance (or build if capable)

Ideal Candidate:

Experience with consumer product prototyping
Mechanical + basic electrical knowledge
Experience with motors / mixing devices is a plus
Practical, solution-oriented mindset

Timeline:

We are aiming for a working prototype within 4–6 weeks

Budget:

$2,000–$8,000 for initial prototype phase, flexible depending on approach.

When Applying:

Please include:

Similar projects (if any)
Your approach to building this
Estimated timeline
