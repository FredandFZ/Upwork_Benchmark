job_name:
New SaaS Website Landing Page Design

job_description:
We need a design for a new B2B SaaS website landing page. We have a logo and brand guide but now need to develop a landing page plus a look-and-feel for follow-on web pages and an associated web UI/UX. The company is launching in the rapidly emerging field of AI agents with the goal of establishing itself as a significant player. Our marketing focus is strictly B2B as opposed to B2C.

There are no physical products or screen shots so the landing page design is wide open (within reason). Initially we would like to see a range of potential design approaches and then jointly iterate towards a final design. The envisaged web design framework is Astro with Tailwind CSS, hosted on AWS S3. Website coding is not required but the design should bear this in mind.

The SaaS web application UI/UX will be fairly traditional (think ChatGPT or Anthropic) although hopefully a bit more stylish/interesting. A tie back to the website is desirable but should not constrain either design. The envisaged UI design/deployment framework is React, TypeScript,
shadcn/ui plus Tailwind. UI/UX coding is not required but the design should bear this in mind.
